# SidePulse

Мини-панель на краю экрана: показывает **загрузку ОЗУ**, **температуру CPU** и
**температуру GPU** в реальном времени. Всегда поверх окон, компактная, в трее.

> «Пульс системы» — узкая панель сбоку, по которой сразу видно, что происходит
> с компьютером, не открывая диспетчер задач.

## Что показывает (MVP)

| Метрика | Источник |
|---|---|
| ОЗУ, занято % и ГБ | `psutil.virtual_memory()` |
| Температура CPU | LibreHardwareMonitor (pythonnet) |
| Температура GPU | LibreHardwareMonitor, фолбэк `pynvml` (NVIDIA) |

Расширяемо: загрузка CPU/GPU %, частота, диски, сеть — по желанию.

## Стек

- Python 3.10+ (проверено на 3.12) + **Tkinter** (окно-оверлей, без рамки, topmost)
- `psutil` — ОЗУ и общая статистика
- `pythonnet` + `LibreHardwareMonitorLib.dll` — температуры CPU/GPU (**рекомендуемый** способ на Windows)
- `pynvml` / `nvidia-ml-py` — фолбэк для NVIDIA
